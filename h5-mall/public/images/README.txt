# 图片放置指南

请将你的图片文件放入以下对应的文件夹中，文件名必须完全匹配（注意大小写和后缀名）。

## 1. 首页轮播图 (Banners)
**存放位置**: `h5-mall/public/images/banners/`

请放入 3 张图片，命名如下：
- `banner1.jpg` (第一张，推荐展示品牌或主打活动)
- `banner2.jpg` (第二张)
- `banner3.jpg` (第三张)

**建议尺寸**: 宽 800px * 高 400px (或者 2:1 比例)

## 2. 商品图片 (Products)
**存放位置**: `h5-mall/public/images/products/`

示例商品图片命名：
- `product1.jpg` (有机小白菜)
- `product2.jpg` (本地胡萝卜)
- `product3.jpg` (有机西兰花)
- ...以此类推

如果你的图片名字不一样，请告诉我，或者在代码里修改文件名。

## 3. 农户头像 (Farmers)
**存放位置**: `h5-mall/public/images/avatars/`

- `farmer1.jpg`
- `farmer2.jpg`
- ...

---
**注意**: 
1. 放入图片后，不需要重启服务器，直接刷新网页即可看到。
2. 如果没有图片，页面上会显示灰色的背景块，但功能是正常的。
